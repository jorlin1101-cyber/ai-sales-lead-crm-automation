## 运行与阅读

以下命令默认使用新版。每次输出目录必须新建；封存报告不能覆盖。

```powershell
.venv\Scripts\python.exe scripts/run_answerability_eval.py run --mode rule_only --out data/runtime/p002-v2-example/rule_only
.venv\Scripts\python.exe scripts/run_answerability_eval.py run --mode mocked_model --out data/runtime/p002-v2-example/mocked_model
.venv\Scripts\python.exe scripts/run_answerability_eval.py review-template --run data/runtime/p002-v2-example/rule_only --run data/runtime/p002-v2-example/mocked_model --out data/runtime/p002-v2-example/review-draft.json
.venv\Scripts\python.exe scripts/run_answerability_eval.py verify-archive --run data/runtime/p002-development/runs-final/rule_only
```

每份报告的 `summary.md` 提供两组汇总及逐轮客户问题、实际回复、预期要点和资料依据。`review-template` 只生成未批准草稿，审核身份和结论不得虚构。`verify-archive` 只证明封存字节完整，不代表业务正确或已接纳。

正式接纳仍需新增案例要求确认、具体输出真实审核、更新后的公开同步范围授权、GitHub实际检查及来源核验、独立新版基线和必需检查配置。以实际完成的证据更新状态。
