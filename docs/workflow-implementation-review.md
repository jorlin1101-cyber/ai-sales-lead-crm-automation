# AI 销售线索优化与逐项复核

日期：2026-09-08。范围：本地代码修改、隔离测试及最小化百炼模型联调；未推送 GitHub、未部署、未向真实客户发送消息或向真实 Notion 写入数据。

## 原问题的逐项结论

### 2026-09-08：由收集信息推进到产品推荐

- 从同一份已配置知识快照中按目的地读取产品手册，不再仅依赖通用报价片段的前三条搜索结果。当前目录包含川西私人定制游、云南家庭游、西藏文化游；不硬编码线路、人数、天数或售价。
- 销售回复先列具体产品、手册线路和时长、匹配依据，再列与客户人数/天数不一致的地方。缺日期或酒店不会阻止初步选品；报价所需信息仍另行确认，预算不当成产品售价。
- 只补充酒店、用车、导游的下一轮也继续生成产品回复；更换目的地会替换推荐。没有对应手册、产品资料不完整、已退订等情形不会捏造或沿用旧产品。
- 标准方案和推荐依据由服务器绑定原始片段，模型补充体验/规则说明；模型成功或回退都保留产品及需调整事项。网页在草稿前增加产品卡片，刷新后可恢复。
- 原有云南产品译文漏掉延长线路的冬季限定，本次依原文补回。匹配是候选方案筛选，尚不代表酒店、车辆、导游或季节供应能力已确认。
- 复核：699 项通过、2 项 PostgreSQL 实机测试跳过，覆盖率 95.21%。75 个源文件类型检查与规范检查通过；独立浏览器两轮真实 `qwen3.7-plus` 调用均理解/生成成功，第二轮仍返回 `Yunnan Family Tour`，无重复缺失项；中英界面切换及 390px 无横向溢出通过。

## 增强功能与边界

1. **会话工作台**：收件箱、完整时间线、刷新恢复、失败请求原 ID 重试；审核通过、驳回、编辑版本、人工已发送回执。已发送不是系统代发，仅操作者记录已执行的外部动作。
2. **草稿与 CRM**：写入已保存分析及已审核草稿，阻止旧版本；成功版本幂等返回；不确定结果查验 Notion 版本标记；更新不重置销售阶段。Notion 通过模拟接口验证，未做真实账户联调。
3. **权限**：`local` 仅回环请求为操作员；`protected` 需至少 32 字符令牌；`public_demo` 为签名 Cookie 隔离的离线访客，不能访问生产 CRM、内部报价或记录外部发送。不是多租户企业权限系统；公网仍需 HTTPS、网关限流和数据保留策略。
4. **RAG + 通义千问**：多轮事实与最近上下文参与查询；目的地改变后只保留当前地区及通用资料；知识片段、检索方法与证据快照可追溯。操作员模式已接入百炼 `qwen3.7-plus`：模型负责提取本轮事实并基于检索证据起草回复，服务器负责缺失问题、状态、审核和引用绑定。每段模型回复只能选择服务器提供的证据编号，服务器再附回原文和 SHA256；不允许模型计算价格、批准商机、发送消息或写 CRM。模型失败时明确记录 `llm_trace` 并回退到 `rag_grounded_template` / `context_template`，不把回退冒充模型成功。访客模式仍保持离线且无密钥权限。
5. **确定性报价**：`POST /conversations/{id}/quote` 使用操作者提供的价格表、Decimal、适用日期/人数/产品/酒店、币种、包含项/排除项/假设和版本指纹。缺失、重叠或冲突拒绝自动算价；默认不提供数字报价。当前是内部估算接口，没有自动把估算塞进客户回复，也不是最终报价审批系统。
6. **入站渠道**：提供时间戳 + HMAC 验签的标准入站接口，默认关闭，消息 ID 幂等。Gmail、企业微信、网站各平台的消息格式和官方验签须由专用适配器接入；本轮没有接通实际邮箱或自动发送渠道。
7. **存储**：增加 `conversation_leases`、`workflow_events`；旧记录迁移保留测试通过。已增加 PostgreSQL CI 服务与迁移/并发/多轮恢复测试；本机无 PostgreSQL，不能把 SQLite 测试当作 PostgreSQL 实机通过。

## 如何复核

本轮最终结果：**699 项通过，2 项 PostgreSQL 实机测试跳过；代码覆盖率 95.21%**。
Ruff 检查、75 个源文件类型检查通过。真实百炼最小化验证中，两轮产品推荐的理解与生成均成功，回复为 `llm_grounded`，产品名、方案和引证保留完整。该验证只证明当前路径可调用，不等于业务答案准确率已通过人工评测。
旧 SQLite 结构迁移后原会话保留测试通过；不据此推断 PostgreSQL 实机迁移已通过。

- 后端完整质量门：`python -m pytest -q`（外网 socket 禁用、原有覆盖率门槛 95% 不变）。
- 静态检查：`python -m ruff check .`、`python -m ruff format --check .`、`python -m mypy src`。
- 离线功能冒烟：`python scripts/ci_offline_smoke.py`。
- 数据库：备份后执行 `python -m alembic upgrade head`。不要为修复启动问题删除旧表或执行 downgrade。
- PostgreSQL：仅在独立测试库设置 `TEST_POSTGRES_URL`，先迁移，再运行 `tests/test_conversation_postgres.py`。
- 浏览器：`python -m uvicorn scripts.review_preview:create_preview --factory --host 127.0.0.1 --port 8011` 启动独立临时数据库、禁用外网和 CRM 的预览；用已安装 Playwright 执行 `node scripts/review_browser.cjs`，默认使用 Chrome。可通过 `PLAYWRIGHT_PATH` 指定已安装模块绝对路径。

浏览器场景包括：三轮消息、更正、时间线失败、刷新、编辑/审核/人工回执、切换语言保留未保存稿、390px 移动端溢出检查、响应丢失后的原消息恢复。
