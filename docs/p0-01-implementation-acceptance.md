状态：开发进行中。依据：最终设计 1.0。开始代码：7cbd8650757ca6754292542d902c4dfb7c39d7df。

## 开发计划

1. 固定数据契约和 22 场景，保留现有业务行为。
2. 实现真实入口回放、隔离、分模式评分及检索和推荐契约复用。
3. 实现不可变报告、人工复核、三类 gate、双基线和可信来源校验。
4. 接入锁定依赖的 CI、命令行及运行说明。
5. 运行针对性测试、完整工程检查、两次离线评测，按下面 26 项记录证据。

真实模型实验、销售标注认可和远端 CI 保护均按实际条件报告，不用本地模拟或开发者自签替代。
